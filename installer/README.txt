RusakbGate — комплект для другого ПК
=====================================

В архиве ключи VPN (profile.json). Не выкладывай архив в открытый доступ.

Установка:
  1. Распакуй ZIP в любую папку.
  2. Запусти INSTALL.cmd (или INSTALL.ps1).
  3. На рабочем столе появится ярлык RusakbGate.
  4. Перед VPN выключи Happ и прочие VPN.
  5. Ярлык -> ПКМ -> Запуск от имени администратора -> ВКЛ.

Обновление: снова распакуй новый ZIP и запусти INSTALL (файлы перезапишутся).
