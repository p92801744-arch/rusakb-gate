# Ядра VPN (не в git — скачай вручную)

Положи в эту папку рядом с RusakbGate.exe после сборки (publish\bin):

| Файл | Откуда |
|------|--------|
| xray.exe | https://github.com/XTLS/Xray-core/releases (windows-64.zip) |
| sing-box.exe | https://github.com/SagerNet/sing-box/releases (windows-amd64) |
| wintun.dll | https://www.wintun.net/ или из zip sing-box |
| geoip.dat, geosite.dat | из zip xray или sing-box |

Минимальные размеры проверяй глазами: exe обычно > 10 МБ, dat — мегабайты, не килобytes HTML-ошибки.
